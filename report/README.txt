POLAR ENCODING AND DECODING OVER AN AWGN CHANNEL — LaTeX REPORT

FILES
- main.tex: complete editable LaTeX report source.
- figures/system_diagram.png: transmitter/channel/receiver block diagram.
- figures/ber_plot.png: BER versus Eb/N0 plot from the report.
- figures/fer_plot.png: FER versus Eb/N0 plot from the report.

COMPILE LOCALLY
1. Install a LaTeX distribution (TeX Live or MiKTeX).
2. Open a terminal in this folder.
3. Run twice:
       pdflatex main.tex
       pdflatex main.tex
   The second pass updates the table of contents and page references.

USE WITH OVERLEAF
1. Upload the ZIP archive to Overleaf as a new project, or upload main.tex and
   the figures folder while preserving the folder structure.
2. Set main.tex as the main document.
3. Select pdfLaTeX as the compiler.

ADD YOUR APPLICATION SCREENSHOTS
Place your original screenshots in the figures folder using these exact names:
- screenshot-message.png

Then compile again. The appendix placeholders will be replaced automatically.
